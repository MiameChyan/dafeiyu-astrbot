# 指令手册（速查表）

> 只列线上实际装了的插件（2026-11-17）。私聊直接发；群聊里 @ 机器人，或以 `/` 开头。
> 标 👑 的指令只有管理员能用。大部分需求也可以直接用自然语言说。

## 长期记忆（LivingMemory）

| 指令 | 作用 |
|---|---|
| `/lmem status` | 记忆库统计；索引维护进行中时显示进度 |
| `/lmem search <关键词> [条数]` | 搜索长期记忆，默认 5 条 |
| `/lmem summarize [条数]` | 立即总结当前会话；给条数时重新总结最近 N 条消息 |
| `/lmem forget <id>` | 删除指定记忆 |
| `/lmem trace [n\|id]` | 查看最近的召回记录：命中了哪些、为什么被过滤 |
| `/lmem migrate-scope <目标> [apply] [来源]` | 把已有记忆迁到另一个作用域；默认只预览，加 `apply` 才写入 |
| `/lmem rebuild-index`、`/lmem rebuild-graph` | 重建文档索引、图谱索引 |
| `/lmem reset` | 重置当前会话的记忆上下文 |
| `/lmem webui` | 管理面板入口（AstrBot 面板 → 插件 → LivingMemory → 视图） |
| `/lmem help` | 完整帮助 |

刚聊过的内容搜不到时，先 `/lmem summarize`。默认要攒满 10 轮对话才会自动总结。

## 群聊读空气（group_chat_plus）

| 指令 | 作用 |
|---|---|
| `/gcp_reset` | 清除插件记录的群聊状态与历史截止点 |
| `/gcp_reset_here` | 只清除当前群 |
| `/gcp_clear_image_cache` | 清除图片描述缓存 |

触发词、概率、启用的群都在插件配置里改，见 [Windows 部署说明](../deploy-windows/README.md)。

## 表情包（stealer）

| 指令 | 作用 |
|---|---|
| `/meme status`、`/meme capacity` | 运行状态、库存容量 |
| `/meme on`、`/meme off` | 开关偷图 |
| `/meme auto_on`、`/meme auto_off` | 开关自动发表情包 |
| `/meme list`、`/meme random` | 列出、随机发一张 |
| `/meme delete`、`/meme blacklist` | 删除、拉黑 |
| `/meme menu` | 完整帮助 |

偷来的图要在插件面板「表情管理」里人工通过才入库。

## 语音开关（face_convert）

| 指令 | 作用 |
|---|---|
| `/语音开`、`/语音关`、`/语音状态` | 当前会话的语音条开关 |

线上还没配语音合成，现在开了也只有文字。

## 定时任务（AstrBot「未来任务」）

在面板 → 未来任务里管理：可以暂停、改时间、加新任务。机器人在对话里能看到自己名下有哪些任务（schedule_awareness 注入）。

## AstrBot 内置指令

| 指令 | 作用 |
|---|---|
| `/help` | 指令帮助 |
| `/reset` | 重置当前会话上下文 |
| `/sid` | 查看会话 ID（配隔离会话、白名单时用得上） |
| `/provider` | 查看或切换模型提供商 |
