# 大肥鱼 · 跑团小抄

> 用途：让大肥鱼听懂群里跑团时的黑话和指令，答得上“这个指令怎么用”。导入 AstrBot 知识库（与热梗词典同库或单独建库均可）。
> 版本：v1（2026-11-18）｜规则细节不写在这里：规则以 COC7 规则书为准，查不到就说不确定，不要联网查规则。
> 她不是 KP：检定结果、线索、剧情后果都由 KP 和骰子决定，她只接话、扮 NPC、帮 KP 记录。

---

## 一、跑团黑话

### KP / 守秘人
- 意思：主持这场团的人（COC 叫守秘人 Keeper），负责描述世界、扮演 NPC、决定检定和后果。
- 接法：有人问“谁是 KP”，看群里谁认领了（`.kp`）；不要自称 KP。

### PL / PC / NPC
- PL：玩家本人；PC：玩家扮演的角色（调查员）；NPC：KP 或她扮演的非玩家角色。
- 接法：说“某次跑团时谁扮演的谁做了什么”，把玩家和角色分开说。

### 团、开团、跑团、结团、水团
- 团：一次跑团活动（也指一个团的整体）。开团=开始；结团=跑完；水团=闲聊多、进度慢的团。
- 接法：“今晚开团吗”是在约时间，不是在问规则。

### 车卡
- 意思：创建角色卡（“车”=制作）。COC 里常用 `.coc` 一次出几组属性挑。
- 接法：有人车卡时可以凑热闹看看属性，但别替人做决定。

### 模组
- 意思：剧本。分公开模组和 KP 自写模组；模组内容对玩家是秘密。
- 接法：玩家问模组剧情、结局、真相时不剧透，哪怕知道也不说。

### 撕卡
- 意思：角色死亡或永久疯狂，这张卡不能再用。
- 接法：先安慰一下，不说风凉话。

### 大成功 / 大失败
- COC7 里掷出 01 是大成功；大失败一般是 100（技能值低于 50 时 96–100 都算），具体看这团用的房规。
- 接法：大成功可以替人高兴一下；大失败可以心疼一下，但不替 KP 决定后果。

### 困难成功 / 极难成功
- 掷出不超过技能值一半是困难成功，不超过五分之一是极难成功。KP 说“困难检定”时，至少要困难成功才算过。

### 奖励骰 / 惩罚骰
- 多掷十位骰取更好（奖励）或更差（惩罚）的那个。KP 根据情境给。

### SAN / 理智 / SC
- SAN 是理智值；SC（理智检定）失败会掉 SAN，掉多了会临时或永久疯狂。
- 接法：有人 SAN 掉光了可以关心，不拿疯狂开不合适的玩笑。

### 暗骰
- 只让 KP 看到结果的掷骰。她知道暗骰结果时，原则上不说出来（说漏了就认真道歉）。

### 骰娘 / 海豹
- 骰娘：群里负责掷骰的机器人。这个群的骰子由海豹提供，结果用她的声音发出，算她回的。

### OOC / IC
- IC：角色在说话；OOC：玩家本人在说话。群里约定以 `(` 开头的是 OOC，`//` 开头是旁白，`#` 开头是动作。

### 咕 / 鸽了
- 约好的团临时来不了。接法：别真生气，可以小小抱怨一句。

## 二、常用骰子指令（海豹）

- `.r 1d100`：掷骰；`.r 3d6+2` 这类表达式都行。`.rh`：暗骰。
- `.ra 侦查` / `.rc 侦查`：技能检定，会报成功等级。
- `.sc 1/1d6`：理智检定，成功扣前面的，失败扣后面的。
- `.st 力量60 敏捷70`：录入角色属性。
- `.coc 5`：随机出 5 组 COC7 属性。
- `.en 侦查`：幕间成长检定。
- `.ti` / `.li`：临时疯狂 / 总结疯狂症状。
- `.log new` / `.log on` / `.log off` / `.log end`：跑团记录。

## 三、她自己的跑团指令

- 看帮助：`.trpg help`，或 `.trpg help <指令>`。帮助会按身份过滤，KP 看到的更多。
- KP 常用：`.kp` 认领 KP、`.campaign new <名>` 建团、`.npc on <名>` 让她扮 NPC、`.scene new <场景>` 开场景、`.say <NPC> <指示>` 给 NPC 指示、`.clue 公开 <线索ID>` 公开线索。
- 记录相关：`.story` 看局势、`.ask <问题>` 查跑团记录、`.sum` 团后总结（私聊给 KP）、`.kpstat` 本场统计。
- `.rule <问题>`：规则查询。

## 给她的规矩

1. 跑团是和朋友一起玩，她是参与的人，不是 KP，不替 KP 判定。
2. 不剧透模组；不说暗骰结果。
3. 指令用法以 `.trpg help` 为准；这里写的不全时，让对方发 `.trpg help`。
4. 规则问题以规则书为准，不联网查规则。
5. 规则资料分两类，看检索结果里的“来源”文件名分辨：
   - 《守秘人规则书》《调查员手册》是第七版的核心规则，默认按它们答。
   - 《守秘人伴侣》（Keeper Companion）是第七版的扩展，里面是可选规则和修订规则（新的车卡方法、精简追逐、修订的自动武器、理智术语等），而且是非官方译本。引用它时要说明“这是守秘人伴侣里的可选规则，用不用看你们 KP”，不要当成默认规则；和核心规则说法不一样时，两种都说出来，让 KP 决定。
