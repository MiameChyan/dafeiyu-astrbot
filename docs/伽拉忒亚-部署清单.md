# 部署清单

记录这台 Windows 电脑上的线上部署走到哪一步。部署步骤见 [Windows 部署说明](../deploy-windows/README.md)，变更记录见 [CHANGELOG](../CHANGELOG.md)。

| 仓库 | 内容 |
|---|---|
| 本仓库 `dafeiyu-astrbot`（公开） | 部署套件、本仓库插件、核心补丁、人格 |
| [dafeiyu-trpg](https://github.com/MiameChyan/dafeiyu-trpg)（私有） | 跑团插件（待重新设计，要和 LivingMemory 对齐） |

## 1. 基础

- [x] Docker Desktop + AstrBot **v4.29.0**（钉版本；核心补丁按这个版本整文件替换）。
- [x] AstrBot 数据放在 Docker 数据卷 `dafeiyu-astrbot-data`；只有插件代码和插件配置从宿主机挂载。
- [x] 停止信号设为 `SIGINT`，安全关闭不会被强杀。
- [x] 核心补丁：按语义分气泡发送、拟人节奏与出站限速、挂钩点（留给 TRPG）。语音补丁已挂载，但没配语音合成，不起作用。

## 2. QQ 协议端

- [x] OpenQQ fork（`dafeiyu` 分支 `5f6d71a`），挂接桌面 QQ NT，反向 WS 到 `127.0.0.1:6199`。
- [x] NapCat 放进 compose 的 `napcat` profile 作备用，默认不启动。
- [x] 掉线监控 `watchdog.py`：OpenQQ 模式，只弹通知、不自动重启。
- [x] 日常启停：根目录的 `启动大肥鱼.ps1` / `安全关闭大肥鱼.ps1`。

## 3. 模型与知识库

- [x] 对话：DeepSeek `deepseek-flash`。
- [x] 嵌入：本机 Ollama `bge-m3`（`ollama_bge-m3`）。另有硅基流动托管的 bge-m3 和 bge 重排序，知识库在用。
- [x] 知识库：AstrBot 自带，热梗词典，按需检索。
