# 伽拉忒亚部署清单

本 fork 在参考项目之上部署「伽拉忒亚」：人设不同，长期记忆换成自建记忆系统，并加入跑团功能。首个演示版本运行在搭档自己的 Windows 电脑上。标「待实现」的步骤要等对应插件写好。

| 仓库 | 内容 |
|---|---|
| 本仓库 `dafeiyu-astrbot`（公开） | 主体：部署套件、原有插件、伽拉忒亚人设、核心补丁、共享库 `lib/dafeiyu-shared` |
| [dafeiyu-memory-system](https://github.com/MiameChyan/dafeiyu-memory-system)（私有） | 五层记忆插件 |
| [dafeiyu-trpg](https://github.com/MiameChyan/dafeiyu-trpg)（私有） | 跑团功能插件，含托管海豹的骰子插件 |

## 1. 主体基础部署

- [ ] 按 [QUICKSTART](../QUICKSTART.md) 完成体检、依赖安装、`.env` 填写，以及 AstrBot 与 NapCat 的安装。
- [ ] AstrBot 版本钉在 **v4.29.0**。参考项目的核心补丁与我们的补丁都按这个版本整文件替换，换版本前必须先重打补丁。
- [ ] 部署 `deploy/patches/` 中的核心补丁：Docker 用 compose 里的只读挂载；本机安装用脚本覆盖，覆盖前备份原文件并核对版本。我们的补丁只开挂钩点（出站捕获 P-M1、分流 P-T1），说明见记忆规格 §16.1 与 TRPG 规格 §5.1。
- [ ] AstrBot 配置 `platform_settings.ignore_bot_self_message` 设为 `true`。
- [ ] NapCat 扫码登录 QQ 小号，昵称「伽拉忒鱼」。
- [ ] 准备 DeepSeek 对话模型与一个嵌入模型。key 只填在 `.env` 或 AstrBot 配置界面里。
- [ ] 用 AstrBot 自带的 Python 运行记忆系统仓库里的环境验证 `tools/m0_verify.py`。

## 2. 人格

- [ ] AstrBot 人格设置填 [伽拉忒亚人格提示词](../persona/伽拉忒亚-人格提示词.md) 的正文，人设依据见 [伽拉忒亚人设](../persona/伽拉忒亚-人设.md)。
- [ ] 部署套件目前组装的仍是上游的 `persona/大肥鱼-人格.md`，改用伽拉忒亚的人格提示词前，以上一步的手动设置为准。
- [ ] 唤醒词「大肥鱼」写在配置里，不写死。昵称跟随所用模型，换模型时只改配置。

## 3. 记忆系统（待实现）

- [ ] 安装记忆插件，停用 LivingMemory。
- [ ] 记忆文件目录放在机器人数据目录下，并设为 git 仓库，仓库级 `core.autocrlf=false`。
- [ ] 改造前基线：在装好 LivingMemory 的主体上运行几天后采集；或跳过，以 M2 阶段数据作为第一个基线。

## 4. 跑团功能（待实现）

- [ ] 安装 sealdice-core。它不直接连接 NapCat，而是连接骰子插件提供的本机 OneBot 端点，由骰子插件托管（TRPG 规格 §9）。
- [ ] 骰娘名称设为「大肥鱼」，按 TRPG 规格 §9 调整自定义文案。
- [ ] 安装 TRPG 的各个插件；启动日志里确认指令撞名自检通过。

## 不入库的内容

账号、密码、API key、QQ 号、机器的 IP，以及 `.env`、记忆文件、数据库、日志和回放，都只留在运行这台电脑上。本仓库是公开的，提交前尤其要检查。
